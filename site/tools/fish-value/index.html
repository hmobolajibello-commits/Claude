Fish value calculator

A fish sells for its species’ base value scaled by weight and then multiplied by whatever mutation and attributes it carries. This models that structure so you can see what a mutation is actually worth before you decide whether to appraise it.

A model of the multiplier structure, not the game’s exact arithmetic — Fisch does not publish its value formula, and weight scaling in particular is an approximation here. Use it to compare two catches, not to predict a sale.
