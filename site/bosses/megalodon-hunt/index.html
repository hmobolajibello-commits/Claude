Megalodon Hunt

Bosses & hunts

Fisch’s signature hunt. It is a server event rather than a fishing spot, which is why the community answer to “how do I get a Megalodon” is a stack of totems rather than a better rod.

Doing it

  1. Bank Sundial Totems — a lot of them.
  2. Cycle the server’s time repeatedly to force hunt events to roll.
  3. When the hunt spawns, everything else on the server stops. Be ready before you start cycling.
